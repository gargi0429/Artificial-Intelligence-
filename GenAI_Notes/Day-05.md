Day 5 – Module 1: Demystifying Generative AI
What is Generative AI?

Generative AI is a type of Artificial Intelligence that can create new content instead of only analyzing existing data.

Examples
Writing emails
Generating code
Creating images
Summarizing documents
Generating SQL queries
Creating reports and presentations
Traditional AI vs Generative AI
Traditional AI	Generative AI
Classifies data	Creates new content
Predicts outcomes	Generates text, images, code
Analyzes information	Produces new information
Works on predefined tasks	Handles open-ended tasks
Example

Traditional AI

Is this email spam?
Will a customer leave the company?

Generative AI

Write a professional email.
Generate a customer retention strategy.
Real-Life Analogy

Imagine a chef:

Traditional AI

Identifies whether a dish is pasta or pizza.

Generative AI

Creates a completely new recipe using available ingredients.

What is an LLM?

LLM stands for Large Language Model.

Examples:

ChatGPT
Claude
Gemini
Llama

LLMs are trained on massive amounts of text data collected from:

Books
Articles
Websites
Documentation
Code repositories

They learn:

Grammar
Patterns
Facts
Relationships between words
Important Concept

LLMs do not think like humans.

They predict:

What is the most likely next word or token?

This prediction process is repeated thousands of times to generate responses.

Why ChatGPT is Called a Super-Powered Autocomplete

When you type on a smartphone keyboard, it predicts the next word.

Example:

Input:
The capital of France is

Prediction:
Paris

ChatGPT works similarly but on a much larger scale.

Instead of predicting one word, it predicts entire paragraphs by continuously selecting the most probable next token.

How ChatGPT Generates Responses
Step 1: User Input

Prompt:

Explain SQL joins.
Step 2: Tokenization

The input is broken into smaller pieces called tokens.

Example:

Explain | SQL | joins
Step 3: Prediction

The model predicts the next most likely token.

SQL joins are...
Step 4: Iteration

The prediction process repeats hundreds of times.

Step 5: Response Generation

A complete answer is produced.

Why Generative AI Feels Smart

Generative AI appears intelligent because it has learned patterns from enormous amounts of data.

However:

⚠️ It predicts patterns.

⚠️ It does not truly understand information.

⚠️ It can sometimes generate incorrect information.

Hallucinations

A hallucination occurs when an AI model confidently provides incorrect or fabricated information.

Example:

Inventing a non-existent book
Generating fake statistics
Creating inaccurate references
Best Practice

Always verify:

Facts
Statistics
References
Important business decisions
First Prompt Engineering Exercise

Try this prompt:

Act as a senior SQL trainer.

Explain INNER JOIN using:
1. Simple English
2. Real-life analogy
3. SQL example
4. Common interview question

Observe how the model follows instructions and structures its response.

Key Takeaways
Generative AI creates new content.
Traditional AI mainly analyzes and predicts.
LLM stands for Large Language Model.
LLMs predict the next token repeatedly.
ChatGPT is often called a Super-Powered Autocomplete.
AI can hallucinate.
Outputs should always be verified.
Formula for Better AI Responses
Prompt + Context + Instructions = Better Output
