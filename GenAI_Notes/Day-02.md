Day 02 - Machine Learning Fundamentals
What is Machine Learning?

Machine Learning (ML) is a subset of Artificial Intelligence that enables computers to learn from data without being explicitly programmed.

Instead of writing rules manually, we provide data and allow the system to discover patterns automatically.

Why Machine Learning?

Traditional programming works well when rules are clearly defined.

For example:

Input + Rules = Output

However, many real-world problems have complex patterns that are difficult to describe using rules.

Examples:

Predicting house prices
Detecting spam emails
Recognizing faces
Predicting customer behavior

Machine Learning solves these problems by learning patterns directly from data.

Relationship Between AI and ML
Artificial Intelligence
        ↓
Machine Learning

AI is the broader field.

Machine Learning is one technique used to achieve AI.

Not every AI system uses ML, but most modern AI applications do.

How Machine Learning Works

A machine learning model learns patterns from historical data.

Basic process:

Data Collection
      ↓
Data Cleaning
      ↓
Model Training
      ↓
Testing
      ↓
Prediction

Example:

A model is trained using previous student placement records.

After training, it predicts whether a new student is likely to be placed.

Types of Machine Learning
Supervised Learning

The model learns from labeled data.

Labeled data means the correct answer is already known.

Example:

Study Hours	Result
2	Fail
8	Pass

Applications:

House Price Prediction
Spam Detection
Student Placement Prediction
Unsupervised Learning

The model learns from unlabeled data.

No correct answers are provided.

The goal is to discover hidden patterns.

Applications:

Customer Segmentation
Market Basket Analysis
Pattern Discovery
Reinforcement Learning

The model learns through rewards and penalties.

The system improves by interacting with an environment.

Applications:

Robotics
Self-driving Cars
Game Playing AI
Underfitting

Underfitting occurs when a model is too simple to learn meaningful patterns.

Characteristics:

High training error
High testing error
Poor predictions

Common Causes:

Insufficient training
Oversimplified model
Lack of useful features
Overfitting

Overfitting occurs when a model memorizes training data rather than learning general patterns.

Characteristics:

Very low training error
High testing error
Poor performance on unseen data

Common Causes:

Excessively complex models
Small datasets
Too much training
Bias-Variance Tradeoff
Bias

Bias measures how far predictions are from the true relationship.

High bias often causes underfitting.

Variance

Variance measures sensitivity to changes in training data.

High variance often causes overfitting.

Goal

Build a model that balances bias and variance to achieve strong performance on unseen data.

Recommendation Systems

Advantages of Machine Learning
Learns from data automatically
Improves prediction accuracy
Handles large datasets
Finds hidden patterns
Enables intelligent automation
Disadvantages of Machine Learning
Requires large amounts of quality data
Can be computationally expensive
Models may become biased
Results can be difficult to interpret
Key Takeaways
Machine Learning is a subset of AI.
Data is the fuel of ML systems.
Supervised, Unsupervised, and Reinforcement Learning are the three primary categories.
Underfitting and Overfitting are fundamental challenges in model development.
The objective is to achieve a balance between bias and variance.
